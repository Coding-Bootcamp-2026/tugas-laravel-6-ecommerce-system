# tugas-laravel-6-ecommerce-system
Tugas untuk membuat aplikasi berbasis web menggunakan framework Laravel. Aplikasi ini akan mensimulasikan sistem E-Commerce skala menengah. Anda akan mempraktikkan keseluruhan proses dari instalasi, merancang database yang cukup kompleks, menggunakan Eloquent untuk relasi antar tabel, hingga membuat operasi CRUD penuh.
